# Docs

Each page does one job, and its folder says which. The folders follow [Diátaxis](https://diataxis.fr).

| You want to | Read |
| --- | --- |
| Try the app for the first time | [Tutorials](tutorials/add-your-first-task.md) |
| Get a task done | [How-to guides](how-to/run-the-checks.md) |
| Look up a fact | [Reference](reference/api.md) |
| Understand a decision | [Explanation](explanation/why-one-repository.md) |

Vale reads these pages. `.vale.ini` picks the rules by folder, so a how-to guide that promises a lesson fails. Run `vale docs`.
